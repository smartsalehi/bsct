# ۵۰۴ واژه ضروری انگلیسی 🇬🇧🃏

یک وب‌سایت تعاملی و کاملاً آفلاین برای یادگیری **۵۰۴ کلمهٔ ضروری انگلیسی** با معنی فارسی، **بدون نیاز به هیچ سرور یا اینترنت**.

## ✨ امکانات

| بخش | توضیح |
| --- | --- |
| 📚 **۴۲ درس** | هر درس ۱۲ کلمه با معنی فارسی، در قالب کارت‌های زیبا |
| 🃏 **فلش‌کارت** | مرور کلمات با چرخاندن کارت، دکمهٔ «یاد گرفتم» و «ضعیف» |
| 📝 **آزمون** | انتخاب تعداد سؤال (۱ تا ۱۰)، محدودهٔ همه یا یک درس، جهت فارسی↔انگلیسی |
| 🔊 **تلفظ** | پخش تلفظ انگلیسی با Web Speech API مرورگر (بدون اینترنت) |
| 🔍 **جستجو** | جستجوی فوری به فارسی یا انگلیسی |
| 👥 **مدیریت کاربران** | ۱۰ کاربر پیش‌فرض + ۱ مدیر؛ ورود/خروج، پیشرفت جدا برای هر کاربر، پنل مدیریت (افزودن، بازنشانی و حذف کاربر) |
| 📊 **پیشرفت** | ذخیرهٔ خودکار در localStorage مرورگر به‌تفکیک هر کاربر، نوار پیشرفت، استریک روزانه |
| 📱 **واکنش‌گرا** | سازگار با موبایل، تبلت و دسکتاپ (RTL کامل فارسی) |

## 🚀 اجرا

دو راه دارید:

### ۱) بدون راه‌اندازی (فقط فایل را باز کنید)
همین پوشه را باز کنید و `index.html` را با مرورگر اجرا کنید (دابل‌کلیک). همه‌چیز آفلاین کار می‌کند.

### ۲) با یک سرور ساده (اختیاری)
برای تست درست خطاها و تشخیص فایل‌ها می‌توانید یک سرور محلی راه بیندازید:

```bash
# با Python
python -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## 🗂 ساختار فایل‌ها

```
504-words/
├── index.html      ← صفحهٔ اصلی (همهٔ بخش‌ها + صفحهٔ ورود + پنل مدیریت)

└── 02 fshc/        ← بک‌آپ نسخهٔ پیشین (پیش از افزودن مدیریت کاربران)
```

## 🧠 نحوهٔ استفاده

1. **درس‌ها** را باز کنید، روی یک درس کلیک کنید و کلمات را مرور کنید.
2. برای هر کلمه دکمهٔ **✓** را بزنید تا «آموخته‌شده» ثبت شود.
3. از **فلش‌کارت** برای مرور سریع استفاده کنید؛ روی کارت کلیک کنید تا معنی را ببینید.
4. با **آزمون** خودتان را محک بزنید (۴ گزینه‌ای، فارسی↔انگلیسی).
5. پیشرفت شما **همین‌طور که هست** در مرورگر ذخیره می‌شود؛ برای شروع دوباره از دکمهٔ «پاک‌کردن پیشرفت» در پایین صفحه استفاده کنید.

## 👥 کاربران

برنامه با **ورود کاربر** کار می‌کند: در اولین بار باز شدن، به‌صورت خودکار با نخستین کاربر عادی (علی) وارد می‌شوید تا تجربهٔ بدون اصطکاک حفظ شود. با دکمهٔ **خروج** در هدر، صفحهٔ ورود ظاهر می‌شود و می‌توانید کاربر دیگری را انتخاب کنید. **پیشرفت هر کاربر کاملاً جدا ذخیره می‌شود.**

### حساب‌های پیش‌فرض

| نقش | نام کاربری | رمز عبور |
| --- | --- | --- |
| 👑 مدیر | `admin` | `admin123` |
| 👤 کاربر | `ali`، `maryam`، `reza`، `sara`، `hossein`، `niloo`، `amir`، `fateme`، `mahdi`، `zahra` | `123456` (همه) |

### پنل مدیریت

پنل «**مدیریت**» فقط برای مدیر (`admin`) نمایش داده می‌شود؛ کاربران عادی حتی با وارد کردن دستی آدرس هم به آن نمی‌رسند. در این پنل می‌توانید:

- **افزودن کاربر** جدید (نام فارسی + نام کاربری انگلیسی + رمز حداقل ۴ نویسه)
- **ورود** به حساب هر کاربر (بدون نیاز به رمز) برای مشاهدهٔ پیشرفت او
- **بازنشانی** پیشرفت یک کاربر
- **حذف** کاربر عادی (مدیر و کاربر جاری قابل حذف نیستند)

## 💾 پیشرفت (localStorage)

پیشرفت هر کاربر با کلید مخصوص خودش در مرورگر ذخیره می‌شود (`vocab504-progress-v1_<نام کاربری>`). پاک‌کردن حافظهٔ مرورگر یا باز کردن در مرورگر دیگر، پیشرفت را از بین می‌برد.

## 🛠 توسعه

- تمام منطق در `app.js` است؛ هیچ وابستگی خارجی (فریم‌ورک یا کتابخانه) ندارد.
- استایل‌ها در `style.css`؛ فونت فارسی Vazirmatn از Google Fonts (اگر آفلاین باشید، فونت سیستم جایگزین می‌شود).
- تست خودکار DOM با `jsdom` در `dom-test.js` موجود است (۶۸ تست: داده، ناوبری، فلش‌کارت، آزمون، جستجو، مودال، localStorage و ماژول کاربران).

```bash
npm install jsdom   # یک‌بار
node dom-test.js    # اجرای ۶۸ تست
```
