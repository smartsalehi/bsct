# حفظ جزء سی‌ام قرآن کریم

یک وب‌اپلیکیشن تعاملی و **کاملاً آفلاین** برای حفظ جزء ۳۰ قرآن (۳۷ سوره، ۵۶۴ آیه) با رابط فارسی و راست‌به‌چپ.

## شروع سریع

فایل `index.html` را با دوبار کلیک در مرورگر باز کنید. هیچ سرور، نصب یا اینترنتی لازم نیست.

> تنها استثنا: فونت‌ها از Google Fonts و صوت تلاوت از CDN خوانده می‌شوند. اگر آفلاین باشید، متن و همهٔ امکانات کار می‌کنند و فونت‌ها به فونت‌های جایگزین سیستم برمی‌گردند؛ فقط تلاوت صوتی نیاز به اینترنت دارد.

## امکانات

| بخش | توضیح |
| --- | --- |
| **خانه** | پیشرفت کلی، رشتهٔ روزهای مطالعه، آیهٔ روز، فهرست سوره‌ها |
| **سوره‌ها** | صفحهٔ هر سوره: متن عثمانی + ترجمهٔ فارسی، پخش پیوسته، علامت‌گذاری حفظ‌شده/مشکل‌دار |
| **فلش‌کارت** | روی هر کارت کلیک کنید تا ترجمه آشکار شود؛ دکمه‌های «حفظ کردم» و «نیاز به تمرین» |
| **آزمون** | چهار حالت: تشخیص ترجمه، آیهٔ بعد، جای‌گذاری در سوره، ترکیبی |
| **جستجو** | جستجوی فارسی یا عربی (با یا بدون اعراب) با هایلایت نتیجه |

### جزئیات مفید

- **جستجوی بدون اعراب:** اعراب، تنوین، تشدید و نشانه‌های وقف نادیده گرفته می‌شوند و «ی/ي» و «ک/ك» و «ه/ة» هم‌ارز هستند. مثلاً «قیامت» و «قيامت» هر دو یک نتیجه می‌دهند.
- **تلاوت صوتی:** پنج قاری (العفاسی، الحصری، المنشاوی، ماهر المعيقلي، الشاطري). در صفحهٔ سوره می‌توانید یک آیه یا کل سوره را پشت‌سرهم بشنوید.
- **ذخیرهٔ خودکار:** پیشرفت در `localStorage` مرورگر ذخیره می‌شود (کلید `juz30-progress-v1`). با دکمهٔ «پاک‌کردن پیشرفت» در پایین صفحه می‌توانید صفر کنید.
- **پنهان‌کردن متن:** دو دکمه در صفحهٔ سوره: پنهان‌کردن ترجمه (برای آزمون از خود) و پنهان‌کردن متن عربی (برای آزمون ترجمه).
- **میان‌بر صفحه‌کلید:** در آزمون، کلیدهای `۱` تا `۴` گزینه‌ها را انتخاب می‌کنند و `Enter` به سؤال بعد می‌رود.

## ساختار فایل‌ها

```
quran/
├── index.html   ساختار صفحه‌ها (SPA، شش نما)
├── style.css    ظاهر و رنگ‌ها، واکنش‌گرا، RTL
├── data.js      دادهٔ کامل جزء ۳۰ (تولیدشده)
├── app.js       منطق برنامه
├── raw/
│   ├── ar.json  پاسخ خام متن عثمانی
│   ├── fa.json  پاسخ خام ترجمهٔ فولادوند
│   └── build_data.py  اسکریپت ساخت data.js از دو فایل بالا
└── dom-test.js  مجموعهٔ آزمون (فقط برای توسعه، jsdom لازم دارد)
```

## داده‌ها از کجا آمده‌اند؟

متن عثمانی از نسخهٔ `quran-uthmani` و ترجمه از نسخهٔ `fa.fooladvand` در [api.alquran.cloud](https://api.alquran.cloud) گرفته شده است. هر آیه شمارهٔ سراسری (`g`) را هم نگه می‌دارد، چون آدرس صوت بر پایهٔ همان ساخته می‌شود:

```
https://cdn.islamic.network/quran/audio/128/{reciter}/{g}.mp3
```

برای بازسازی `data.js`:

```bash
python raw/build_data.py
```

## توسعه و آزمون

فایل‌های `index.html`/`style.css`/`data.js`/`app.js` بدون هیچ ابزار ساخت اجرا می‌شوند. اگر خواستید مجموعهٔ آزمون را اجرا کنید:

```bash
npm install jsdom        # فقط برای آزمون
node dom-test.js
```

آزمون‌ها با jsdom برنامه را در یک DOM مجازی بالا می‌آورند و داده، ناوبری، فلش‌کارت، آزمون، جستجو، صدا و ذخیره‌سازی را می‌سنجند. **این وابستگی‌ها فقط برای توسعه‌اند؛ سایت منتشرشده به آن‌ها نیاز ندارد.**

## نکته‌های پیاده‌سازی

- بدون چارچوب و بدون مرحلهٔ ساخت: فقط JavaScript خالص و CSS.
- همهٔ شماره‌ها با ارقام فارسی (`۰۱۲۳۴۵۶۷۸۹`) نمایش داده می‌شوند.
- جهت صفحه `rtl` است؛ حروف عربی با فونت Amiri Quran و متن فارسی با Vazirmatn نمایش داده می‌شوند.
- `init()` محافظ `appStarted` دارد تا اگر اتفاقی دو بار صدا زده شود، شنونده‌های کلیک دوباره بسته نشوند (وگرنه هر کلیک دو بار اجرا می‌شد و اثر هم را خنثی می‌کرد).
